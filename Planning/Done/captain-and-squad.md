# Captain + Squad

Viking pawn (Enhanced Input: move / look / zoom / jump / sprint), clip locomotion (idle / walk / run / jump), floating nameplates. The squad starts empty. Entering Relion adds **Sam**; entering Kanfold adds **Alex** as well. Companions follow in battle-plan slots; the squad camera frames the group and lifts off terrain. The captain's nameplate stays hidden until a companion is with him.
