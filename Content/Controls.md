# Controls

Input Actions and the mapping context can be replaced with Content assets on the character later. If unset, C++ creates transient defaults so PIE works immediately.

## General (all modes)

| Action | Keyboard | Gamepad |
|--------|----------|---------|
| Move | WASD (true sight) | Left stick (true sight) |
| Look | Right mouse button (hold) | Right stick |
| Pointer | Mouse | — |
| Click to move | Left click (raven sight) | — |
| Zoom | Mouse wheel (raven sight) | — |
| Jump | Space | A / Cross |
| Sprint | Left Shift | Left stick click |
| True sight / raven sight | F9 (after raven sight is enabled) | — |
| Main menu | F10 | — |
| Inventory | / | — |
| Debug readout | F12 | — |
| Close an event message | Click, Enter, Esc, or F10 | — |
