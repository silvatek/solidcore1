# Multiple storage containers

Status: New

## Story

The player has more than one storage container in a stronghold. Each container keeps its own items. The player opens one container and sees that container's slots. The chest the company already has still starts with the same items. [Basic furniture management](basic-furniture-management.md) places at most one chest in the company's stronghold. This story is what a second container needs.
